Liforma example

Experience widget

This page is ordinary marketing copy. The avatar in the corner is an <liforma-experience-widget> with position="bottom-right" — no host CSS required. The SDK loads thumb plates from the public preview API, warms the player after idle, then opens the conversation on one click.

Use position="static" (default) when you want to place the FAB yourself with an enclosing div. Optional offset sets the corner inset (default 16).

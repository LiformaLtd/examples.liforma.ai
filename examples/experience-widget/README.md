# Experience widget examples

Corner launcher: collapsed thumb until click, then an in-page overlay conversation.

| Framework | Folder | Local URL |
| --- | --- | --- |
| SvelteKit | `sveltekit/` | http://localhost:4002 |
| Vanilla HTML | `vanilla/` | http://localhost:4002 |
| Next.js | `nextjs/` | http://localhost:4002 |
| React (Vite) | `react-vite/` | http://localhost:4002 |

**Read first in each port:** `Demo.tsx` / `+page.svelte` — the `ExperienceWidget` mount.

**Hosted demo:** https://experience-widget.examples.liforma.ai/

From the repo root: `./start`, `./start sveltekit`, `./start nextjs`, or `./start react-vite`.

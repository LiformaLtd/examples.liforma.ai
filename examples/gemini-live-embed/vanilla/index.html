1. Connect Gemini, then start the player

Paste your Gemini API key, click Connect, then tap Start experience on the avatar. This app’s WebSocket proxy forwards to Gemini with your key (demo-only — use a real backend in production).

API keys stay on the server — this demo uses a same-origin WS proxy at /api/gemini-live. Setup (model / system instruction) is injected by the proxy; see config.js (GEMINI_LIVE_* env). See the Gemini BYO docs and Gemini console.

# Basic embed examples

The minimal Liforma hello-world: one experience id, one embed component.

| Framework | Folder | Local URL |
| --- | --- | --- |
| SvelteKit | `sveltekit/` | http://localhost:4001 |
| Vanilla HTML | `vanilla/` | http://localhost:4001 |

From the repo root: `./start` (vanilla) or `./start sveltekit`.

1. Connect LiveKit, then start the player

Click Connect to mint a participant token (server env LIVEKIT_URL / LIVEKIT_API_KEY / LIVEKIT_API_SECRET), then tap Start experience on the avatar. An agent in the room (identity starting with agent) must publish audio.

This is bring-your-own LiveKit voice — not Liforma’s future transport: livekit adapter. See the LiveKit BYO docs.

# Spanish Tutor (SvelteKit)

Full lesson-based app with API-backed catalog and `<liforma-experience>` embed.

## Run

From repo root:

```bash
./start sveltekit
```

Or only this app:

```bash
npm install
npm run dev
```

http://localhost:4001

Optional `LIFORMA_API_KEY` in `.env` loads your project catalog from `https://api.liforma.ai` (see `.env.example`).
